# Changelog

## `1.0.1-alpha`

- Historical Mode получил автоматически движущийся `SimulationClock`.
- Добавлен выбор скорости `1x`, `5x`, `10x`, `15x`, `20x`, `50x`, `100x` и `1000x` без скачков времени при переключении.
- Quotes, candles, charts, cache и исполнение сделок синхронизированы с текущей точкой симуляции и не раскрывают будущие данные.
- Добавлена круглосуточная виртуальная торговля всеми поддерживаемыми активами в Live и Historical Mode.
- Закрытие реальной биржи больше не блокирует сделки: используется последняя доступная реальная котировка без генерации искусственных цен.
- Торговые часы и основные exchange holidays сохранены как market-data metadata с учётом timezone.
- При достижении реального настоящего Historical-игра автоматически завершается с сохранением финального портфеля и истории.
- Добавлена автономная подготовка через `Нажми на меня перед запуском.bat` и запуск через `Запустить PaperForge.bat` без ручной сборки `.exe`.
- Project-local runtime, caches и dependency data централизованы внутри `.paperforge`.
